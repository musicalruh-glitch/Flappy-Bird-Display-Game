### **Flappy Bird Display Game**

I built a hand held game, the in game name being  "Flappy Bird Soul." The game is inspired by Undertale, (like all my other Half Life projects) and it was originally supposed to be a Flappy Bird game, hence the name but it's inspired by the attack patterns in game Undertale, sharing the same sprites and music. All credits for sprites, attack patterns, style, and music go to Toby Fox, this product is not for commercial use, it's for my own leisure, because if they won't make the merch just make it yourself! In any case, go play Undertale, it's awesome.
